# 实时鱼漂检测框选实施进度

处理时间：2026-09-19（Asia/Shanghai）
关联规划：[实时鱼漂检测框选与尺寸动作判定实施规划书](20260919-172118-实时鱼漂检测框选与尺寸动作判定实施规划书.md)

## 已实现

- 移除相机画面内红色基准线和绿色阈值线。
- 保留模型检测框，并在框右侧显示可见预览区域的 `W × H px`。
- 尺寸标签支持右侧空间不足时翻到框左侧，并限制在预览边界内。
- `PreviewView` 固定为 `FILL_CENTER + COMPATIBLE`，与当前等比 `CENTER_CROP` 映射保持一致。
- 新增纯 Kotlin `DetectionCoordinateMapper`，支持 FIT/CENTER_CROP、输入框裁剪、预览边界裁剪和可见像素尺寸计算。
- 帧指标携带分析源图像宽高，为后续 CameraX 矩阵映射保留几何输入。
- 新增坐标映射单元测试和尺寸标签单元测试。
- Preview 与 ImageAnalysis 通过同一个 CameraX `ViewPort` 和 `UseCaseGroup` 绑定，并统一 `targetRotation`。
- 使用 `ImageProxyTransformFactory + CoordinateTransform + PreviewView.outputTransform` 将检测框映射到真实预览坐标。
- ImageProxy 预处理改为识别 `cropRect` 和 `rotationDegrees` 的等比 letterbox，padding 使用 114/255。
- `CameraFrame` 携带 `ModelInputTransform`；LiteRT 输出先去除 letterbox padding，再恢复为旋转后分析源归一化坐标。
- CameraX 映射前将旋转后检测框逆旋转回原始 crop 坐标，避免 90°/270° 双旋转。
- Preview 输出矩阵在主线程缓存，分析线程不直接读取 `PreviewView.outputTransform`。

## 当前边界

- CameraX 坐标矩阵、旋转、crop 和 letterbox 已接入；真实鱼漂框与物体的像素级重合仍需固定鱼漂实体或标准回放素材验证。
- 当前 UI 每 250ms 更新检测框，动作判定仍在分析线程逐帧执行；尚未实现单独的 10–15Hz UI 节流流。
- 动作判定仍以框中心 Y 为主，宽高和面积尚未接入触发状态机。
- 当前设备显示的真实模型状态仍需以签名 `fish_float` 模型 descriptor 和性能门禁确认，不能用 MockDetector 或通用模型误框作为生产验收证据。
